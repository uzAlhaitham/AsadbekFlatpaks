# Asadbek Akasha System

Genshin Impact profile viewer with Akasha.cv ranking.

## Features

- Character builds viewer
- Artifacts and weapons stats
- RV / CV values calculation
- Profile comparison
- Akasha.cv API integration

## Download

### Windows

Download the installer from:
https://github.com/uzAlhaitham/AsadbekFlatpaks/releases/tag/bundles-v1

File: Asadbek.s.Akasha.System.Setup.1.0.0-1.exe (77 MB)

Steps:
1. Download the installer
2. Run it
3. Follow setup instructions

### Linux

File: asadbek.akasha.cv-x86_64.flatpak (139 MB)

Install:
flatpak install --user asadbek.akasha.cv-x86_64.flatpak

Or via repository:
flatpak remote-add --if-not-exists asadbekflatpaks https://uzAlhaitham.github.io/AsadbekFlatpaks/asadbekflatpaks.flatpakrepo
flatpak install asadbekflatpaks asadbek.akasha.cv
